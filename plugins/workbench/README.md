## 结构

```
dsh-workbench/
├── package.json        # dsh.bundle.patch + dsh.client.inject 声明
├── cordis.patch.yml    # 注册 host 插件条目
└── lib/
    ├── host/index.js   # host 插件（fs/preset/git 路由 + /todo 命令 + DSH 原生多代理编排）
    └── client.js       # client bundle（外壳、6 页、Agent 工具栏、任务看板、文件视图、专家页、风格页）
```

## 安装（已装）

```sh
dsh plugin --profile desktop add C:\YourWorkbench\plugins\workbench
```

## 开发与迭代（重要）

改 `lib/client.js` 是常态，以下机制保证"改坏了也能快速恢复、不白屏"：

### 1. 改完保存 → 刷新页面即生效（无需重启应用）

桌面端宿主内置了 bundle 监听（~500ms 轮询）：改完 `lib/client.js` **保存**后，
宿主会自动重新哈希并推送 rebuilt 帧（已验证）。由于桌面配置下客户端热替换
（client-hmr）存在 appShell 限制，页面不会自动换新——在桌面窗口里按 **Ctrl+R**
（或 F5）刷新页面即可加载新代码，全程**不用重启应用**，秒级生效。

> 例外：**语法错误**（文件无法解析）时页面会停留在上一次可用状态；
> 用下面的自检先拦住语法问题。

### 2. 改前自检（一条命令）

```sh
pnpm check          # = node --check（语法）+ eslint no-undef（未定义标识符）
```

eslint 的 `no-undef` 能抓住"引用了但没定义"的组件/变量（比如之前的 `WbDiag`），
这是白屏的头号原因。自检通过再保存/重启，基本不会翻车。

### 3. 出错不白屏（错误遮罩 + 安全模式）

- 任何未捕获的脚本错误 / Promise 拒绝 → 全屏红色错误页（含堆栈），可点"重新加载"或"进入安全模式"。
- 渲染错误由 `WbErrorBoundary` 捕获并显示堆栈 + "进入安全模式"按钮。
- **安全模式**（`localStorage wb.safe=1`）：工作台 UI 暂时停用，显示最小恢复页，
  修好代码后点"退出安全模式"即恢复——永远不会被自己的改动锁在门外。

### 4. 核弹开关（彻底禁用工作台，恢复原生 UI）

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\disable-workbench.ps1   # 禁用
powershell -ExecutionPolicy Bypass -File .\tools\enable-workbench.ps1    # 恢复
```

脚本会备份并替换 `~/.dsh/profiles/desktop/` 的 `package.json` / `cordis.patch.yml`，
**重启桌面端后生效**。仅当工作台完全无法加载（比如语法错误导致连安全模式都进不去）时使用。

### 推荐迭代循环

```
改 lib/client.js → 保存 → HMR 自动生效（观察页面）
  ├─ 正常 → 继续改
  ├─ 错误页 → 看堆栈 → 修复 → 保存 → 自动恢复
  └─ 白屏/没反应 → node --check + pnpm check 查语法/未定义 → 修复 → 保存
实在不行 → 错误页"进入安全模式"或 tools\disable-workbench.ps1
```

## 详细方案

见 `..\工作台方案清单.md`（工作区根目录）。

### 项目文件夹选择

- “添加项目 → 浏览…”优先调用 Host 原生文件夹选择框（`POST /api/dsh-workbench/fs/pick-folder`，
  基于 Electron `dialog.showOpenDialog`，主进程实现），不依赖已废弃的 `File.path` 或
  `window.webUtils`（Electron 32+ 已移除，旧方式在部分环境报“无法从当前环境读取文件夹绝对路径”）。
- 非桌面环境（如纯 Web/普通 Node）下原生对话框不可用，自动回退到 HTML 文件夹输入。

## 风格页

- 原生主题偏好：浅色、深色、跟随系统，继续通过 DSH `ThemeRuntime` 持久化。
- 工作台视觉层：强调色、壁纸、界面不透明度、暗色遮罩、毛玻璃、字体大小、圆角和密度均实时预览。
- 壁纸在客户端缩放并转为 WebP，Host 只接受受限大小的 PNG/JPEG/WebP data URL；不会加载远程图片。
- 内置风格可直接应用，自定义风格预设最多保存 20 个。预设不复制壁纸数据，应用预设时保留当前壁纸。
- 对话风格与专家人格分离；默认、简洁、详尽、引导、自定义五种模式通过独立 `systemPrompt` 段全局生效。
- 风格设置保存在 `DSH_HOME/dsh-workbench-style.json`，采用串行队列和同目录原子替换。
- Host 路由：`GET /api/dsh-workbench/style/read`、`POST /api/dsh-workbench/style/write`。
- 风格 Host 冒烟测试：`node tools/smoke-style.mjs`，使用独立临时用户目录，不触碰真实数据。

## 多AI协作工作台（P2.5，进行中）

- 协作模式：快速问答（单个回答代理，轻量）与多AI协作（任务拆解 + 子代理编排），

  "执行异常"并提示需要人工介入；代理卡显示尝试次数。
- 右侧面板：概览（进行中/已完成/等待队列/进度/运行时）与代理状态两个新 Tab，
  原决策 Tab 保留。
- Host 冒烟测试：`node tools/smoke-watchdog.mjs`（超时重试 + 需人工介入 + 快速问答标记）。

## 监控页（P3）

- 数据源：`dsh-usage-stats` 插件接口（`summary` / `balance` / `sessions`，同源回环）+ 会话 store。
- 账户：余额、累计费用、预计可用天数（按日均费用估算）、Token 总量、费用趋势柱状图。
- 用量：Token 分项（输入/缓存读/缓存写/输出）、缓存命中率、主要模型、按模型与按天明细，
  支持 7/30/90/365 天区间。
- 会话：当前会话中消耗最高的前 8 个（费用/Token/轮次/最近请求时间）。
- 实时：当前会话实时用量（含本轮进行中消耗、最近模型）、协作任务运行状态，每 10 秒刷新。
- 告警：余额/日预算/区间预算阈值（本机 localStorage），触发后监控页横幅 + 导航栏红点。

- 接口：`GET /api/dsh-workbench/workflows/list`、`POST .../workflows/schedule`、
  `POST .../workflows/run`、`POST .../workflows/remove`；存储 `DSH_HOME/dsh-workbench-workflows.json`。

## 对话窗口多AI模式（P2.6）

- 左侧栏「单 AI / 多 AI」切换，按会话记忆；多 AI 自动执行发送 → 模型实测 → 规划 → 启动 →
  主代理汇总，默认按复杂度自动选择快速回答或完整编排，可切「始终编排」。
- 用户消息与主代理最终报告（或失败原因）进入对话流；子代理浮层只显示运行情况，
  工作时自动展开、可手动折叠、完成后自动折叠。
- 模型实测：极小请求验证 + 10 分钟缓存 + 单次最多 12 个（Provider 轮转）+ 失败继承主会话；
  输入条「模型」面板支持「全部实测」。
- @ 引用浮层（想法库/项目文件）、附件上传与拖放；引用以 `sourceRefs` 持久化并强制 `[来源: 名称]`，
  缺失时产生验收风险。
- 规划 JSON 截断自动补全 + 失败重试一次；任务进度 SSE 实时推送（轮询兜底）。

## 双层任务系统

- **今日聚焦**：右侧快捷栏只展示正在进行、阻塞和今日优先任务，并提示 WIP 超过 2 项；支持快速收集和一键展开任务中心。
- **任务中心信息架构**：一级导航为“聚焦 / 想法库 / 任务 / AI 协作 / 复盘”；看板、列表、时间线和模板收进“任务”的二级视图，减少一级导航拥挤。任务详情仍使用右侧抽屉，不离开当前上下文。
- **全局左栏入口**：任务中心和想法库从右侧会话工具栏迁移到工作台左栏，任何主页面都可打开；任务中心展开时左栏保持可见。左栏按“工作区 / 资源与自动化 / 个性与系统”分组，右栏只保留与当前会话直接相关的详细信息、Git、文件和蒸馏。
- **临时想法速记**：临时想法输入框位于 Agent 会话列表栏的项目选择器下方，不占用全局导航；它跟随会话栏当前选择的项目，无项目时保存为全局想法，支持 `Ctrl/Command + Enter` 存入并展示最近两条待处理想法。全局导航只保留任务中心与想法库入口及数量徽标。
- **默认专注布局**：每次桌面工作台启动时，全局左侧导航默认收为图标窄栏，右侧会话工具栏默认关闭；会话列表和临时想法保持可见。左栏可通过底部箭头展开，右栏可通过对话区右侧浮动按钮重新打开，本次使用中的开合互不影响。
- **想法库**：突发想法作为独立实体进入收件箱，不会自动污染任务看板或启动代理。支持待评估、稍后、已推进和归档状态；AI 整理按需触发，给出摘要、标签、影响/投入评分、建议去向和执行前问题。
- **可追溯提升**：想法可转成普通任务或 AI 协作任务，原始想法仍保留并记录关联 ID，方便回看“为什么做”和最初上下文。
- **项目范围**：顶部可切换“当前项目 / 全部项目 / 全局任务”。切换项目只改变筛选范围，不会删除原项目任务；“全部项目”会显示任务所属项目，“全局任务”存放不绑定项目的事项。
- **工作台任务**：独立保存在 `~/.dsh/dsh-workbench-tasks.json`，包含稳定 ID、五种状态、优先级、执行者、备注、计划/截止日期、时长、标签、阻塞原因、来源会话和时间戳，不受 Agent 新轮次覆盖。
- **任务组**：整批导入 Agent 计划时可保留计划标题、步骤顺序、来源会话和当前项目；任务中心按组展示总步骤与完成进度，组内每一步仍可独立流转状态。
- **流程模板**：Agent 计划可保存为不绑定项目的全局模板；模板视图支持查看步骤、应用到当前项目和删除。应用时会生成一组全新的待办任务，不影响模板本身。
- **Agent 当前计划**：继续读取 DSH 原生 `todos` 投影并保留 `/todo` 写入能力；单步“+”会作为独立任务收进当前项目；“全部收进工作台”可选择保存为任务组、拆成独立任务或保存为流程模板；也可从任务详情送回当前 Agent 计划。
- **任务中心项目快切**：任务中心保持打开时，可在顶部项目下拉框直接切换正在查看的项目；不会切换 Agent 会话或关闭任务中心。筛选、新建任务和“应用模板”都会使用任务中心内选择的项目。
- **AI 协作台**：采用“左侧协作任务 / 中间方案与交付 / 右侧决策”的主从布局。想法从想法库提升后，LLM 生成可审查的主代理、子代理工作包、依赖、并发上限和验收清单；此阶段只保存方案，不会执行。
- **多轮编排**：执行前可写反馈并重新生成 V2、V3 等方案；每个版本保留生成时间和修改依据。执行后按轮次保存状态、代理快照和验收意见，方案历史与执行历史分开查看。
- **多模型代理**：编排器可按“质量优先 / 智能平衡 / 成本优先 / 全部手动”从 DSH 当前模型目录建议分配；用户可为主代理和每个子代理单独调整，留空则继承主会话。Host 会校验模型仍然可用，并记录代理实际使用的 provider/model。
- **双重人工关口**：只有用户点击“确认并执行”后，Host 才会调用 DSH 官方 `subagents.start('spawn', …)` 启动子代理；主代理在子代理结束后汇总证据并提交报告，但只有用户可以“通过验收”或“要求修改”。
- **持久执行记录**：想法、方案、每个代理的状态、子会话 ID、交接结果、主代理报告、修改意见与验收状态都保存在同一任务库中，并按项目隔离。桌面端重启不会丢记录；正在执行的单次子代理会被标记为中断，保留已有结果并允许重新规划。
- **项目执行边界**：编排可以在任务中心切换项目后管理；真正启动时会自动寻找该项目当前在线的顶层会话作为父代理，避免子代理误在另一个项目目录执行。若目标项目没有在线会话，会明确提示先打开该项目会话。
- **导入反馈**：“全部收进工作台”的保存方式弹窗挂载在页面顶层，避免被右侧滚动区域裁剪；当前计划没有步骤时会直接显示原因，不再表现为按钮无响应。
- **快捷操作**：`Y/I/B/O/L/T/R/P` 切换聚焦、想法库、看板、AI 协作、列表、时间线、复盘和模板，`C` 新建，`/` 或 `Ctrl/Command+K` 搜索，`Esc` 关闭详情/任务中心；拖拽之外始终提供状态下拉替代操作。
- Host 路由：`GET /api/dsh-workbench/tasks/list`、`POST /api/dsh-workbench/tasks/mutate`。
- 写入采用进程内串行队列 + 同目录临时文件替换；Host 冒烟测试使用独立临时用户目录，不触碰真实 `~/.dsh`。
- 多代理 Host 冒烟测试：`npm run test:orchestration`，覆盖运行时发现、独立想法实体与转换、模型目录、AI 方案生成、主/子代理结构清洗、方案版本和版本 4 数据落盘。

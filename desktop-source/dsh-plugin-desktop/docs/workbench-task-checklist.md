## 6. 执行顺序建议

1. 明早统一测评：按第 1 节抽查 V1/V2（其余可自动化项已全部完成）。
2. 实际使用后给 S3 反馈。
3. 如需正式发布：按 release-sop.md 走（版本号、gh release、Redis 版本键、自动更新验证）。
4. R7（签名证书/跨平台/便携版/旧数据迁移）在外部条件具备时按需启动。

## 7. 每次迭代固定流程

现状核验 → 方案（含决策点）→ 备份 → 实施 → 回归（smoke/eslint/评测/GUI）→ 更新文档 →
提交（不推送，除非要求）→ 部署运行端（备份 + 复制 + 重启）→ GUI 验收。

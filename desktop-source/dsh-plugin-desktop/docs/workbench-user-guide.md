# 工作台用户手册（2026-08-20）

> 面向日常使用者。开发与部署见 [plugins/workbench/README.md](../../plugins/workbench/README.md)。

## 1. 工作台是什么

DeepSeek Harness Desktop 内的个人 AI 工作台，提供六页能力（Agent 工作区 / 知识库 / 专家 /
风格 / 监控 / 工作流）、任务中心（聚焦 / 想法库 / 任务 / AI 协作 / 复盘）以及项目配置。

## 2. Agent 工作区（日常对话）

- 左侧会话栏：项目切换、新建会话、临时想法速记（`Ctrl/Command + Enter` 存入）、会话置顶/重命名/归档。
- 临时想法下方是「单 AI / 多 AI」切换，按会话记忆。
  - 单 AI：与原生对话完全一致。
  - 多 AI：发送后自动「模型实测 → 规划 → 启动编排 → 主代理汇总」；默认按复杂度自动选择
    快速回答或完整编排，可切换「始终编排」。
- 对话流：用户消息与主代理最终报告（或失败原因）直接出现在对话里，可跳转任务中心查看完整记录。
- 子代理浮层：只显示运行情况（主/子代理状态、工作中高亮）；任务进行时自动展开、可手动折叠、
  完成后自动折叠。
- 输入条：`@` 引用想法库/项目文件；`+` 添加附件（支持拖放）；「模型」打开实测面板，
  可查看可用模型并「全部实测」整个目录；「自动/始终编排」切换策略。

## 3. 任务中心

- 一级视图：聚焦 / 想法库 / 任务 / AI 协作 / 复盘。
- 任务二级视图：看板 / 列表 / 时间线 / 模板。
- 想法库：临时想法可评估、稍后、推进、归档；可「交给 AI 团队」转协作，或转普通任务。
- AI 协作：Quick-Add 直接创建任务；方案可反馈重生成（V2/V3…）；确认后执行子代理；
  验收由你决定（通过 / 要求修改）。
- 协作任务自动同步进看板与复盘：创建编排即生成任务卡（带「AI 协作」标识），
  规划/执行/验收中=进行中，已验收=已完成，失败/取消=阻塞；点卡片直达编排详情，
  拖到「已完成」即验收、拖到「阻塞」需确认取消。
- 任务卡可锁定（🔒），防止被覆盖；详情里也有锁定开关。
- 快捷键：`Y/I/B/O/L/T/R/P` 切换视图，`C` 新建，`/` 或 `Ctrl/Command+K` 搜索，`Esc` 关闭。

## 4. 知识库

- Obsidian 兼容 Markdown Vault：01-Inbox → 02-Atomic → 03-MOCs → 04-Projects →
  05-Archive / 00-Raw；支持检索（BM25 + 图谱 + 本地 BGE 向量 + LLM 重排可选）、
  蒸馏入库、维护（去重/断链/置信度）、评测集（50 题，recall@5=1.0）。
- 条目带置信度依据（来源/验证/一致性/新鲜度/使用）；项目经验（experience）默认沉淀 02-Atomic，
  半自动提炼成知识点需人工确认。

## 5. 专家页

- 每位专家 = 一套预设（人格 + 工具组合）；「调用」用该专家开新会话，「编辑」打开对话窗口让 AI 改，
  支持复制、删除。已产生内容的会话不能中途换专家。

## 6. 风格页

- 外观：主题（亮/暗/跟随系统）、强调色、壁纸、透明度、暗色遮罩、毛玻璃、字体、圆角、密度；
  预设可保存/切换，重启保持。
- 对话风格：默认 / 简洁 / 详细 / 苏格拉底 / 自定义；风格页设置全局默认，
  「详细信息」工具栏可设置「对话风格（本会话）」按会话覆盖。

## 7. 监控页

- 账户（余额/累计费用/预计可用天数/趋势）、用量（Token 分项/命中率/模型/按天）、
  会话（消耗最高）、实时（当前会话用量 + 协作状态）、告警（余额/日/区间阈值，
  页面横幅 + 导航红点）。

## 8. 工作流页

- 模板库（默认日报/晨报、会议纪要、调研写作、表格清洗），一键运行生成任务组；
  支持定时调度（间隔 1–10080 分钟，仅在桌面端运行期间触发）。

## 9. 项目配置（右侧工具栏「项目配置」栏）

- 会话专属内容：查看/追加本会话的约定与进度，存于本机应用数据目录，**不写入项目文件夹**；
  会自动注入多 AI 规划提示词。
- 项目规则：自动发现项目内 AGENTS.md / CLAUDE.md / README 等；可追加，
  没有时一键「初始化 AGENTS.md」（会写入项目文件夹，请知悉）。
- 项目备注：备注/技术栈/注入目录 + 「AI 自动精炼」（读 README 与规则生成结构化备注，可一键填入）。

## 10. 数据与安全

- 数据文件在应用数据目录（`harness-home`）：任务/风格/记忆/知识/工作流/项目上下文均以 JSON 或
  Markdown 保存；会话专属内容在 `sessions/<项目>/<会话>/`。
- 文件接口仅本机回环，只允许读写已注册工作区内的文件，越界返回 403。

## 11. 常用快捷键

| 按键 | 作用 |
|---|---|
| `Y / I / B / O / L / T / R / P` | 聚焦 / 想法库 / 看板 / AI 协作 / 列表 / 时间线 / 复盘 / 模板 |
| `C` | 新建任务 |
| `/` 或 `Ctrl/Command+K` | 搜索 |
| `Esc` | 关闭详情 / 任务中心 |
| `Ctrl/Command+Enter` | 临时想法存入 |

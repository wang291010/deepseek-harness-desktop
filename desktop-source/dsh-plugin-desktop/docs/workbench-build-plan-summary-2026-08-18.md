## 三、已完成

- P0 完成：`dsh-workbench` 插件包（Client + Host）、接入 desktop profile、bundle 注入、Host 路由与 `/todo` 命令、禁用/恢复回滚脚本、错误边界与安全模式。
- P1 主体完成：root 外壳接管、6 页导航（Agent/知识库/专家/风格/监控/工作流）、Agent 三栏布局、自研会话/项目面板、右侧工具栏、插件商店与设置入口、状态记忆；默认收起布局（最左导航为图标栏、右侧工具栏默认关闭、可手动展开）。

- 左侧工作区重构：任务中心与想法库成为一级入口，临时想法卡放入会话列表栏（项目选择器下方），右侧工具栏只保留当前会话相关工具。
- 全部改动均有备份 + 真实桌面截图验收（想法库、AI 协作、左栏展开/收起、默认专注布局等）。

## 六、持续遵守的约束

- A 端（日常）与 B 端（桌面）不能同时打开同一会话；B 端故障不影响 A 端。
- 修改前先备份；profile JSON 无 BOM。
- Client 改动刷新即生效；Host 路由/命令与专家 preset 改动需重启。
- 文件接口仅本机回环访问；发布前做敏感内容审计（API key、聊天记录、凭据不得上传）。
- 旧 DSH 数据不迁移不删除，除非用户明确决定。

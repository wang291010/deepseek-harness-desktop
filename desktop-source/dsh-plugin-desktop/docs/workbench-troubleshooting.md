# 工作台故障排查（2026-08-20）

## 1. 页面白屏或红色错误页

- 未捕获脚本错误 / Promise 拒绝会显示全屏错误页（含堆栈），可「重新加载」或「进入安全模式」。
- 渲染错误由错误边界捕获，同样可进入安全模式。
- 安全模式（`localStorage wb.safe=1`）：工作台 UI 停用，显示最小恢复页；修好代码后点「退出安全模式」。
- 彻底禁用/恢复：`tools/disable-workbench.ps1` / `tools/enable-workbench.ps1`（重启桌面端生效）。

## 2. 方案生成失败「Unexpected end of JSON input」

- 已内置修复：输出被截断时自动补全括号并重试一次；若仍失败，对话流/任务中心会显示失败原因。
- 可点「模型」实测面板看模型可用性，或换「始终编排」重试。

## 3. 多代理执行失败 / 子代理超时

- 子代理单次超时默认 15 分钟（`DSH_WORKBENCH_WORKER_TIMEOUT_MS` 可调），失败自动重试最多 2 次。
- 失败原因已结构化：任务卡/日志会显示 stopReason / error / message 等字段，便于反馈。
- 若集中在某个模型（如 ai-gateway 部分旧模型），可重新发送让方案换用其它模型；
  模型健康度跟踪已列入后续增强。

## 4. 模型实测很慢或「全部实测」久

- 普通实测最多 12 个（按 Provider 轮转），约十几秒；「全部实测」会测整个目录（可能 1–2 分钟）。
- 结果缓存 10 分钟；全部失败时代理继承主会话模型。

## 5. 任务中心看不到协作任务

- 创建编排会自动生成看板任务卡（带「AI 协作」标识）并随阶段同步；如果没出现，
  点任务中心右上角刷新或切换项目范围（当前项目 / 全部项目 / 全局任务）。

## 6. 对话风格没生效

- 检查是「全局」（风格页）还是「本会话」（详细信息工具栏）；会话级覆盖优先于全局。
- 会话级设置保存在应用数据目录，重启不丢失。

## 7. 端口 / 重启相关

- 桌面端 API 端口每次重启会变；Host 路由改动需重启桌面端，Client 改动刷新页面即可。
- 若调试端口需要：以 `--remote-debugging-port=9224` 启动桌面端。

## 8. 数据文件位置

- 任务/风格/记忆/知识索引/评测：应用数据目录 `harness-home/dsh-workbench-*.json`。
- 知识库 Markdown：`harness-home/knowledge/`。
- 会话专属内容：`harness-home/sessions/<项目>/<会话>/dsh-workbench-session.md`。
- 项目规则：项目文件夹内（AGENTS.md 等），会话专属内容不写项目。

## 9. 仍无法解决

- 收集：错误页堆栈 / 编排记录（任务中心 AI 协作详情）/ `harness-home/dsh-workbench-host.log`
  最近片段，交给维护者。

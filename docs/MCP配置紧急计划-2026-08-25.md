# MCP 配置紧急计划（2026-08-25）

## 目标

在桌面应用的“设置”中提供独立 MCP 配置页，不并入工作台插件或插件商店。配置保存到标准 DSH settings 文档，应用重启后由桌面启动层生成官方 `@deepseek-ai/dsh-mcp-client` rows。

## 本次范围

- 独立“设置 → MCP”页面。
- stdio 与 Streamable HTTP 两种传输。
- 服务器启用/停用、名称、命令/参数/环境变量、工作目录、URL/请求头、调用超时。
- `serverName` 唯一性、传输必填项和 URL 校验。
- 保存后重启，避免运行中的 MCP 工具集合与配置不一致。
- 断线自动重连策略：启用开关、首次/最大延迟、连续失败次数上限，遵循官方客户端约束。
- MCP 配置不进入 `dsh-workbench`，插件商店后续可独立重做。

## 验收顺序

1. 设置页能看到 MCP 独立菜单并新增、编辑、删除服务器。
2. 保存后 settings 文档包含 `dsh-mcp` 命名空间，敏感值只在输入区编辑，不在列表额外展示。
3. 重启后启用项生成官方 `@deepseek-ai/dsh-mcp-client` 配置；停用项不生成 row。
4. 重复名称、stdio 缺命令、HTTP 缺失/非法 URL 被拒绝。
5. 普通模式回归、源码构建和真实 MCP stdio/HTTP 连接分别验证；真实连接不通过时保留原始错误，不改写为代码通过。
6. 本地真实 stdio/Streamable HTTP 集成测试需覆盖工具发现、调用、命名和释放；外网服务、密钥和用户配置不作为自动化测试依赖。

## 后续不纳入本批次

- 插件商店 MCP 安装入口。
- MCP Resources/Prompts UI（当前官方桥接仅注册 tools）。
- 在线热重载；配置变更统一重启生效。
